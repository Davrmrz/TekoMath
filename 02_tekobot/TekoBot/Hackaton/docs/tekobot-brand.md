# TekoBot y tejuxi

Proyecto: **TekoBot**. Tutor: **tejuxi**. El logo, favicon y avatar usan `assets/images/tejuxi-face.png`. Los botones de envío, pistas, resolver problemas y opciones rápidas incorporan morado #7138c9, con texto blanco o morado oscuro sobre lavanda. Se conserva el verde del pañuelo como parte de la identidad.

Se conservaron las claves históricas de almacenamiento y nombres de bases de datos para mantener las conversaciones existentes.

## Preparación del logo

Herramienta: imagegen integrada, modo edición con fondo transparente. Referencia aportada por el usuario: `WhatsApp Image 2026-09-26 at 13.36.26 (1).jpeg`.

Prompt utilizado:

> Use case: background-extraction. Create a logo asset from the provided mascot, which is the edit target. Isolate ONLY its smiling head/face, retaining the original dark brown and cream spotted tegu lizard design, large purple eyes, open smiling mouth, same pose and illustration style. Remove body, hands, neck scarf, bulb, all decoration and black background. Single centered face, tight square framing with small transparent padding, clean edges, genuine transparent background. No text, no new details. Save the output PNG for use as TekoBot logo and tutor tejuxi avatar.

Verificación visual realizada en escritorio (1365 px) y celular (390 px): imagen y avatares cargan, los botones adoptan el morado y no existe desbordamiento horizontal.
