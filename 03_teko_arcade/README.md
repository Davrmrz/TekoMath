# 03 — Teko Arcade (Gamificación & Videojuegos Matemáticos)

Módulo de aprendizaje gamificado desarrollado en **React + TypeScript + Vite**.

## 📁 Archivos del Módulo
* `juego.php`: Contenedor e interfaz web de lanzamiento a pantalla completa.
* `juego.css`: Estilos de integración y barra superior de TEKO Arcade.
* `juego.js`: Comunicación postMessage y sincronización entre iframe y la plataforma.
* `../../TEKOARCADE/`: Proyecto completo de frontend con los 6 juegos matemáticos.

## 🎮 Catálogo de Juegos
1. **🔺 Triangle Forge:** Exploración y cálculo del Seno.
2. **〰️ Signal Sync:** Sincronización y período del Coseno.
3. **↗️ Vector Launch:** Dirección y pendiente con Tangente.
4. **◫ Pair Matrix:** Relaciones y emparejamiento con Cosecante.
5. **⚡ Ratio Rush:** Velocidad de cálculo con Secante.
6. **📈 Graph Lab:** Laboratorio y asíntotas de Cotangente.
